# Vibely (Flutter)

First slice of the Flutter app, ported from the web preview.

- 5-tab shell: Games, Rooms, Chats, Discover, Me
- Neon light-blue / white / light-pink theme (`lib/theme/vibely_theme.dart`)
- Room list and room screen with seat grid (UI only, no audio)

Local-only: no backend, payments, real chat delivery or voice audio yet.

Run: `flutter pub get` then `flutter run`.
